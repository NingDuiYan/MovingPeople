# 世界与场景

## 地形高度场(`scripts/utils.js:44`)

```js
heightAt(x, z):
  r = hypot(x, z);  if (r >= ISLAND_RADIUS) return -4;
  base   = smoothstep(R*0.92, R*0.2, r)                    // 同心衰减,越靠中心越高
  noise  = sin(x*.28 + z*.11) * cos(z*.19 + x*.07) * .8
         + sin(x*.09 - z*.23 + 1.3) * .9
         + cos(x*.45) * sin(z*.41) * .35
  h      = base * 5.2 + noise * (.35 + .65 * base) - 0.6
  shore  = smoothstep(R*0.98, R*0.72, r)                   // 海岸过渡
  return h * shore + (1 - shore) * -1.8
```

常量:`ISLAND_RADIUS = 40`、`WATER_LEVEL = 0`、`WALK_SPEED = 2.4`、`RUN_SPEED = 6.0`。岛心约 4–6 m,滩涂向水下过渡,`r >= 40` 全水下。

**纯确定性、零依赖、无三角函数以外的随机**——正因如此,地形网格、角色贴地、相机防穿地、雷达海岸线才能共用一份公式而永远一致。改它会同时改变这三处以及所有 `heightAt` 驱动的摆放(岩石、晶簇、灯笼的落点高度)。

## 碰撞规则

- 登记:`addObstacle(x, z, r, top)` → `{ x, z, r, top }`
- 判定(`main.js:580`):`footY >= o.top` 跳过(矮物不挡路、站高处不被脚下石头拦住);否则按 `r + PLAYER_RADIUS(0.36)` 沿法线推出,最多 3 轮
- 兜底(`main.js:656`):推出后仍 `penetrationAt > 1e-3`(重叠小圆互相打架、几帧不收敛)就退回上一帧位置
- 世界边界:`clampToIsland` 把半径压到 `ISLAND_RADIUS * 0.955 = 38.2`,拉回后仍要再 `resolveObstacles` + 再 `clampToIsland`

## 布局约束

- 出生点 `(2, 2)`,`SPAWN_CLEAR = 9` 半径内不生成岩石与晶簇,避免开场镜头被挡
- 岩石要求 `h >= 0.5`、晶簇要求 `h >= 0.7`、灯笼 `h >= 0.4`,都在水面之上
- 塔、集装箱、栈桥、管道、交互物都是硬编码坐标——改地形后需要人工复核它们是否还"站得住"

## 随机序列的纪律

所有 `rand()` 调用共享一条序列:`sc = 0.45 + rand() * 1.55` 之后立刻取 `sy`(`island.js:252` 的注释 "先取值,保持随机序列与旧版一致")。往中间插入新的 `rand()` 会平移后续所有物体位置——不是 bug,但要在提交信息里说清楚,避免被误认为回归。
