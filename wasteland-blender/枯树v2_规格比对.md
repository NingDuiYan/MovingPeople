## 3. 文档 ↔ 参考图的冲突（已按"图优先"处置，可一键切回）

① **细根数**：文档说"共 8 条"，但逐根只列出 6 条分叉 → 另 2 条从根盘裙边出（`COLLAR_FINE_ROOTS`）。
② **分叉高度**：文档 0.5 m，参考图到 1 m 以上两根仍缠在一起 → 0.5 m 作为数学分叉点，截面重叠到约 0.9 m 得到"编织"感。
③ **根长 / 张开度**（影响最大）：文档给 2.2–3.5 m（张开 6.4–7.0 m），参考图实测张开只有约 **1.8–2.0 m**（≈ 树高的 1/3）。
照文档做会读成"蜘蛛腿"，还会伸进轿车的占地。交付用 `ROOT_LEN_SCALE = 0.44`（张开约 2.9 m，与场景比例协调）；
严格照文档把该常量改成 `1.00` 即可，粗细曲线按文档长度归一化，所以缩短时只砍外段、不压扁整根，
末端是钝头而不是针尖（参考图的"短粗钝头根爪"）。

## 4. 可调开关

| 常量               | 默认                                  | 作用                                                                    |
| ------------------ | ------------------------------------- | ----------------------------------------------------------------------- |
| `DIA_GAIN`         | 1.28                                  | 全树半径补偿（抵消 `resize_tree` 的 ×0.78；漏接一处就有一段特别细）     |
| `ROOT_LEN_SCALE`   | 0.44                                  | 主根长度系数（1.00 = 严格照文档；下调是为了“短粗钝头根爪”）             |
| `ROOT_TAPER_POW`   | 1.60                                  | 根径衰减指数，>1 让前段几乎不收、外端才收尖                             |
| `COLLAR_RIDGE_MAX` | 0.52                                  | 板根脊半径（×2 ≈ 根盘直径；0.60 会在地面撑出一圈平台）                  |
| `COLLAR_FLARE_Z`   | 0.42                                  | 脊的张开高度（配指数 2.2；太高立成斜坡板、太低摊平台）                  |
| `BUTTRESS_FIN`     | True                                  | 板根鳍薄板；根又细又长时会戳出竖刀，必须配 `DIA_GAIN` + 短根            |
| `FLUTE_TRUNK`      | `((3,0.10,2.6,0.0),(6,0.30,4.2,0.0))` | 多组纵沟叠乘：三大叶断面 + 深沟 + 相位对齐的细针缝                      |
| `SIDES_TRUNK`      | 36                                    | 必须能被沟数整除（36 = 6×6），否则沟底掉在两个顶点之间、只挖到 82% 深度 |
| `COLLAR_PLATE_W`   | 0.42                                  | 每条板根角向半宽（弧度），越小沟越深                                    |
| `SEED`             | 20260701                              | 细枝/细根随机量，改种子只影响这些抖动                                   |
