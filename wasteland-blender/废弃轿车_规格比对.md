## 3. 与文档的差异（都写在脚本常量里，可一键改回）

1. **车顶高 1.40 m ≠ 文档 1.3 m**：1.3 m 的车顶会让风档倾角压到 30° 以内，读成「贴地楔子」；
   参考图里车顶到腰线的比例更接近 1.40 m。改回文档值只需要动 `ROOF_Z`。
2. **文档写「前门距车头 1.5–2.8 m」，实现按车头到车尾换算成 3 条门缝**（`DOOR_X`）：文档的区间是从车头量起还是从车身中心量起没有交代，
   按参考图的车门比例（前门略短于后门）取的是中值。
3. **右下轮 sink 0.045 m**：文档写「右后轮陷得最深」但没给数值；0.045 m 是从参考图轮胎埋深反推的，改 `sink` 表即可。
4. **锈片与流痕是几何件**：参考图的锈是贴图级细节。这里为了「不引入外部贴图」的硬约束，用小棱柱与薄条带近似，
   代价是凑近看能发现锈片「浮」在钣金上 6 mm。真正解决要把锈**烘焙成贴图**。
5. **格栅/大灯/尾灯是贴面薄盒**：没有真实凹陷（布尔在这台车上会把 2,133 面打成碎片），远看成立体、近看是「贴在车头的一层」。

## 4. 可调开关

| 常量 / 函数                  | 位置              | 作用                                                                           |
| ---------------------------- | ----------------- | ------------------------------------------------------------------------------ |
| `ROOF_Z`                     | 顶部常量          | 车顶高度（文档 1.3 / 当前 1.40）                                               |
| `L_HALF` / `WHEEL_HALF`      | 顶部常量          | 车长半 / 轮距半                                                                |
| `DOOR_X`                     | 顶部常量          | 三条门缝的 x 位置                                                              |
| `WIN`                        | 顶部常量          | 前后门窗洞的 x 范围                                                            |
| `sink` 表                    | `_wheel()` 调用处 | 每个轮子的陷入深度                                                             |
| `SPUR` / `_flake_side` 参数  | 车身装配段        | 锈片数量与尺寸                                                                 |
| `_paint()` 的 4 个 ramp 区间 | `_paint()`        | 主锈 / 厚锈 / 露底 / 高度权重的分界                                            |
| `_merge_parts()`             | build() 末尾      | 关掉它就会回到 194 个碎片对象（GLB 会变大、drawcall 变多）                     |
| `CAR_X`                      | 顶部常量          | 车身落点 x（世界），**4.85**；原 6.55 会让车尾溢出画幅右边界 138 px            |
| 倒角参数                     | 壳体三角化之后    | `bmesh.ops.bevel(offset=0.010, segments=2)`，只对二面角 >28° 且边长 >0.02 的边 |
| `_shade_smooth_by_angle()`   | build() 收尾      | 30° 内平滑、之外保持硬边；返回处理对象数                                       |

## 5. 与参考图仍有差距

1. ~~方块低模、棱线硬~~：已给侧围加 `bmesh.ops.bevel`（二面角 >28° 的边、offset 0.010、2 段、clamp_overlap）并对合并后的 10 个对象统一 `_shade_smooth_by_angle(30°)`；圆角过渡有了，但**格栅 / 大灯 / 尾灯仍是贴面薄盒**，不是真实凹陷（布尔会把车壳打成碎片）。
2. ~~车顶锈斑密度低于文档~~：顶面锈片 8 → **22 片**，另加每侧 4 条顶面短流痕与一层顶面积沙。
3. ~~锈色偏亮偏橙~~：主锈已压到 (0.155,0.062,0.040)→(0.086,0.038,0.026) 两级、露底 (0.124,0.100,0.072)，hub (0.085,0.042,0.026) / flake (0.058,0.030,0.020)；`wst_export.FLAT` 的 `wst_mat_car_paint` = (0.095,0.044,0.028)。区域 mean 现在是 `91.5,59.3,39.2`，参考图 `79.5,56.7,43.5`——**蓝通道还偏低 4**（偏橙）。
4. ~~轮胎没真的磨平~~：接地判据已按 sink 自适应（见 §2），四个轮子都真实压进沙面；胎面仍没有"磨平的平面"这一级几何细节。
5. 车漆上缺参考图那种**大片剥落到露底的斑块**：现在是噪声分层，读起来是均匀锈，缺大色块。
